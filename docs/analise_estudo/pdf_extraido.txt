=== PÁGINA 1 ===
Conceitos Básicos 
População: É o conjunto de todos os objetos ou  pessoas que possuem uma 
mesma característica. 
Amostra: É uma parte da população que mantém sua característica. Ex: Em um estudo sobre o 
infarto pelo menos 80% da amostra deve ser acima de 40 anos de idade. 
Parâmetro: São dados obtidos da população, tendo 100% de confiança. 
Estatística: São dados obtidos de uma amostra,  trabalhando normalmente com 95% ou 99% 
de confiança. 
Natureza Básica: O estudo é utilizado para obtenção de um conceito sobre o tema. 
Natureza Aplicada: O estudo utiliza os resultados para uma aplicação prática. 
Dados primários: dados obtidos direto da fonte 
Dados secundários: dados obtidos de forma indireta. 
 
Tipos de dados 
Quantitativa: Os dados obtidos são de forma numérica. Podendo ser contínua ou discreta. 
Ex (contínua): Peso, Altura, Creatinina 
Ex (discreta): Qtd de pessoas, Idade 
 
Qualitativa: Os dados obtidos são de forma não numérica. Podendo ser nominal ou ordinal. 
Ex (Nominal): Tipo de doença, atividade física, etc 
Ex (Ordinal): Estágio da doença, Classificação e questionário (ruim, regular, bom, ótimo) 
 
Tipo de Abordagem 
Quantitativa: É trabalhado um teste estatístico,  pode ser em variáveis qualitativas 
ou quantitativas.  
Qualitativa: Normalmente é expresso um parecer, uma opinião ou discussão sobre o assunto. 
 
Tipos de Estudo 
OBSERVACIONAL: Apenas anota -se o s dados, sem que haja uma influência direta sobre o 
mesmo. 
Ex. Estudo sobre a altura, Idade 
 
EXPERIMENTO: É aplicado um tratamento sobre o paciente e depois analisado o efeito.  
Ex: Aferir a pressão sistólica depois de uma caminhada. 
 
Tipo de estudo em relação ao tempo 
Restrospectivo: Dados são coletados do passado. 
Ex: Estudo da evolução do sedentarismo nos últimos 10 anos. 
Trasversal: São os dados obtidos no presente. 
Ex: Estudo de um novo tratamento na pesquisa. 
Prospectivo: Avaliação de um evento futuro (desfecho). Ou projeção futura. 
Ex: Acompanhamento do resultado de uma nova vacina depois de 5 anos. 
Longitudinal: Análise dos dados ao longo do tempo

Teste t de Student 
É um teste paramétrico utilizado para comparar a média entre duas 
populações a partir de suas amostras, considerando o erro amostral gerado 
por cada amostra. 
Pré-requisitos. 
1) Amostra deve ser aleatória. 
2) Possui normalidade ou n ≥ 30. 
3) Possui variâncias iguais (para teste t independente) 
4) Valores de outliers extremos devem ser excluídos e outliers suaves 
deve-se usar o bom senso. 
Definições básicas: 
Amostras independentes: os grupos não possuem relação entre si. 
Amostras pareadas: os dados devem ser escritos em forma de pares, ou 
seja, são grupos relacionados entre si. 
Teste unilateral: quando pretende-se analisar apenas melhora ou piora. 
Teste bilateral : quando pretende -se verificar se existe diferença entre 
grupos, como por exemplo, verificar se duas amostras fazem parte de uma 
mesma população. 
Análise: 
p>0,05 – Não possui diferença significativa entre as médias. 
p≤0,05 – Possui diferença significativa entre as médias com 95% de 
confiabilidade. 
p≤0,01 – Possui diferença significativa entre as médias com 99% de 
confiabilidade.

Teste não paramétrico 
 
É um teste utilizado quando não se verifica os pré -requisitos necessários para 
os testes a ser utilizado. Como no caso do teste T de Student  quando não é 
verificado a normalidade dos dados, é necessário aplicar o teste equivalente e 
não paramétrico como se segue. 
 
Teste t de Student independente  – utiliza o teste de Mann -Whitney para 
equivalência. 
 
Teste t de Student pareado – utiliza o teste de Wilcoxon para equivalência. 
 
 
 
 
Teste ANOVA (análise de variância) 
 
É um teste paramétrico utilizado para comparar as médias de três grupos ou 
mais, tendo como pré-requisitos: 
 
1) Amostra aleatória 
2) Possui normalidade ou n ≥ 30 
3) Possui variâncias iguais (onde uma variância pode ser até 9 vezes maior 
do que a outra). 
4) Se existir outlier extremo, o valor deve ser excluído, o suave usa -se o 
“bom senso”. 
 
Análise. 
No caso do ANOVA, utiliza -se o valor p similar ao teste t de Student, onde em 
alguns casos (ou programas). Usa -se o teste auxiliar  (post hoc ) de Tukey ou 
teste t (LSD).
